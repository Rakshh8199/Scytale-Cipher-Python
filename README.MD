
# Scytale Cipher Encryption and Decryption

## CNS Mini Project

A Python-based desktop application for encryption and
decryption using the Scytale Transposition Cipher.

## Technologies Used
- Python 3
- Tkinter GUI
- Scytale Cipher Algorithm

## Features
- Encrypt plaintext messages
- Decrypt ciphertext messages
- Key-based encryption and decryption
- Scytale matrix visualization
- Copy results to clipboard
- Clear input and output

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run:

   python scytale_app.py

## Example

Plaintext: HELLOWORLD

Key: 4

Encrypted Text: HOLEWDLOLR

Decrypted Text: HELLOWORLD

## Project Objective

To demonstrate encryption and decryption using
the ancient Scytale transposition cipher.

## Subject
Cryptography and Network Security (CNS)

## Note
This cipher is intended for educational purposes
and is not secure for modern applications.
